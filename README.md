## 二、Apple Gift Card 购买前你必须搞清楚的几件事

### 1. 礼品卡和 Apple ID 地区必须匹配

这是新手最容易踩的第一个坑。Apple Gift Card 是分地区的，美区的卡只能给美区 Apple ID 兑换，日区的卡只能给日区 ID 充值，不能跨区使用。如果你拿一张美区礼品卡去国区账号兑换，系统会直接提示"此代码无法在你的商店中兑换"。

所以下单前，先确认你的 Apple ID 地区。如果还没注册外区 ID，可以考虑直接买"带账号"版本的礼品卡套餐——商家会把一个已经充好值的美区 Apple ID 一起交付给你，省去自己注册的麻烦。

### 2. 兑换时会扣除一定税费

这点很多人不知道。在美区兑换礼品卡后，实际进入余额的金额可能会比卡面值略低，因为 Apple 会根据你的账号地区税率扣除一定税费。比如兑换一张 10 美金卡，到账余额可能是 9.x 美金。这不是商家的问题，而是 Apple 官方的扣税机制，所有正规渠道都一样。

### 3. 余额可以用来买什么、不能用来买什么

根据 Apple 官方说明，Apple Account 余额可用于：

- App Store 购买 App、游戏、应用内购买
- 订阅 Apple Music、Apple TV+、Apple Arcade、iCloud+
- 在 iTunes Store 购买音乐、电影
- 在 Apple Books 购买电子书和有声书

但要注意，**部分订阅类服务在首次开通时可能仍要求绑定有效支付方式**，余额不能完全替代信用卡。如果你的目标是订阅 ChatGPT Plus 这类第三方服务，建议先用小额卡测试，确认余额可用后再大额充值。

### 4. 发货后通常不支持退款

卡密类商品本质上是"虚拟货币"，一旦发货，卡号和兑换码就交付到你手里了，商家无法回收。所以几乎所有正规卡密平台都规定"发货后不支持任何理由退款"。下单前务必确认地区和面值选对了。
